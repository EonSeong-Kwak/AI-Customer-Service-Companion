## 第一部分：评分体系重构

### 1.1 问题诊断

通过实际对话案例发现评分体系的根本缺陷：

| 案例描述 | 原评分 | 问题 |
|----------|--------|------|
| 客服专业解答15+知识点，烦躁值降20 | 46分 | 专业能力不被认可 |
| 客服完全不回答，直接结束 | 27分 | 效率分80分荒谬 |
| 客服辱骂客户"傻逼""弱智" | 12分 | 辱骂还有分数 |
| 客服完成所有业务，服务良好 | 69分 | 评分偏低 |

**根本问题**：
1. 效率分轮数奖励独立于业务产出 → "越快崩溃，效率分越高"
2. 业务分只算目标完成率 → 专业解答但目标未完成只得低分
3. 情绪管理基础分过高 → 沉默也有60分
4. 缺少合规校验 → 辱骂客户无惩罚

### 1.2 解决方案：五维度评分体系

| 维度 | 权重 | 核心指标 | 解决的问题 |
|------|------|----------|------------|
| 专业知识分 | 40% | 踩分点覆盖率 | 解决"专业不被认可" |
| 服务态度分 | 25% | 烦躁值控制 + 安抚表现 | 解决"情绪分虚高" |
| 沟通效率分 | 15% | 有效轮率（绑定业务产出） | 解决"效率分虚高" |
| 问题解决分 | 20% | 方案完整性 + 客户执行率 | 解决"目标完成率单一" |
| 合规校验 | 一票否决 | 辱骂/违规承诺 | 解决"辱骂无惩罚" |

### 1.3 评分验证

| 案例 | 原评分 | 新评分 | 变化 | 合理性 |
|------|--------|--------|------|--------|
| 专业客服（对话1） | 46分 | 81分 | +35分 | 专业解答被认可 |
| 完全不回答（对话2） | 27分 | 0分 | -27分 | 合理归零 |
| 辱骂客户（对话3） | 12分 | 0分 | -12分 | 一票否决 |
| 服务良好（对话4） | 69分 | 82分 | +13分 | 服务被认可 |

## 一、专业知识分（40%权重）
| 合规性校验 | 一票否决 | 辱骂/违规承诺 | 职业道德底线 |

---

## 一、专业知识分（40%权重）

### 定义

客服是否掌握了业务知识，能否给出正确、完整的解答。

### 计算公式

```
专业知识分 = 踩分点覆盖率 × 100

踩分点覆盖率 = Σ(命中踩分点权重) / Σ(所有踩分点权重)
```

### 设计理念

- **不依赖客户是否配合**：只看客服是否说对了，不看客户是否接受
- **部分命中也计分**：避免"全有或全无"的评分方式
- **专业能力独立评价**：客服知识能力不应被客户跳话题拖累

### 示例

```
对话1：覆盖15+业务知识点，踩分点覆盖率约85%
专业知识分 = 85分

对话2：完全未回答
专业知识分 = 0分

对话3：辱骂客户，无业务解答
专业知识分 = 0分
```

---

## 二、服务态度分（25%权重）

### 定义

客服是否有良好的服务态度，能否安抚客户情绪。

### 计算公式

```
服务态度分 = 基础分20 + 烦躁值控制30 + 安抚表现30 + 同理心20
```

### 分项计算

#### 2.1 基础分（20分）
- 有实质对话（≥1轮）→ 20分
- 0轮对话 → 0分

#### 2.2 烦躁值控制（30分）

| 烦躁值净下降 | 得分 |
|--------------|------|
| >30 | 30 |
| 20-30 | 25 |
| 10-20 | 20 |
| ≤10 | 10 |
| 净上升 | 5 |
| 挂断 | 0（整项） |

#### 2.3 安抚表现（30分）

```
安抚表现分 = (有安抚话术的轮数 / 总轮数) × 30

安抚话术关键词：抱歉、理解、给您带来不便、帮您、不好意思、别急
```

#### 2.4 同理心（20分）

```
同理心分 = (有同理心话术的轮数 / 总轮数) × 20

同理心话术关键词：我理解您、换做是我、体会您的、心情我理解
```

### 示例

```
对话1：烦躁值20→0（降20），16轮有8轮安抚，4轮同理心
服务态度分 = 20 + 25 + (8/16×30) + (4/16×20) = 20 + 25 + 15 + 5 = 65分

对话4：烦躁值60→28（降32），14轮有6轮安抚，3轮同理心
服务态度分 = 20 + 30 + (6/14×30) + (3/14×20) = 20 + 30 + 13 + 4 = 67分
```

---

## 三、沟通效率分（15%权重）

### 定义

客服能否高效推进业务，避免无效轮次。

### 计算公式

```
沟通效率分 = 有效轮率分 + 轮数效率分

有效轮率分 = (有效轮数 / 总轮数) × 60
轮数效率分 = min(预期轮数 / 实际轮数, 1) × 40
```

### 分项计算

#### 3.1 有效轮率（60分）

```
有效轮 = 有踩分点命中 或 有安抚话术的轮次

有效轮率分 = (有效轮数 / 总轮数) × 60
```

#### 3.2 轮数效率（40分）

```
轮数效率分 = min(预期轮数 / max(实际轮数, 1), 1) × 40

特殊情况：
- 0轮 → 轮数效率分 = 0
- 业务完成度为0 → 整项0分
```

### 设计理念

- **业务产出绑定**：没有业务完成时，效率分直接归零
- **避免"越快越好"误区**：有效轮数更重要，避免客服敷衍了事

### 示例

```
对话1：16轮，12轮有效，预期轮数13
沟通效率分 = (12/16×60) + (min(13/16,1)×40) = 45 + 32 = 77分

对话2：0轮
沟通效率分 = 0分

对话4：14轮，10轮有效，预期轮数12
沟通效率分 = (10/14×60) + (min(12/14,1)×40) = 43 + 34 = 77分
```

## 四、问题解决分（20%权重）

### 定义

客户问题是否真正被解决，业务目标是否达成。

### 计算公式

```
问题解决分 = 方案完整性分 + 客户执行率分 + 客户满意度分

方案完整性分 = 踩分点覆盖率 × 50
客户执行率分 = 客户执行率 × 30
客户满意度分 = 客户满意度 × 20
```

### 分项计算

#### 4.1 方案完整性（50分）

```
方案完整性分 = 踩分点覆盖率 × 50

说明：客服是否给出了完整的解决方案（基于踩分点覆盖）
```

#### 4.2 客户执行率（30分）

```
客户执行率 = 客户按方案操作/确认的轮数 / 相关业务轮数

客户执行率分 = 客户执行率 × 30
```

#### 4.3 客户满意度（20分）

```
客户满意度检测：
- 客户表示"好的""谢谢""明白了" → 满意
- 客户表示"行吧""知道了" → 基本满意
- 客户继续抱怨/投诉 → 不满意

客户满意度分 = 满意度评分 × 20
```

### 设计理念

- **区分客服能力和客户执行**：方案完整给客服认可，客户不执行不拖累客服
- **结果导向**：问题真正解决才给高分

### 示例

```
对话1：方案完整性85%，客户执行率30%，客户满意度70%
问题解决分 = 85%×50 + 30%×30 + 70%×20 = 42.5 + 9 + 14 = 65.5分

对话4：方案完整性80%，客户执行率90%，客户满意度80%
问题解决分 = 80%×50 + 90%×30 + 80%×20 = 40 + 27 + 16 = 83分
```

## 五、合规性校验（一票否决）

### 定义

客服是否遵守职业规范，无辱骂、违规承诺等行为。

### 校验机制

在综合分计算后，进行合规性校验：

```
合规性校验（按优先级）：
1. 严重辱骂（带器官/家人的辱骂）≥1次 → 综合分直接归0
2. 一般辱骂（傻逼、弱智、蠢货等）≥1次 → 综合分直接归0
3. 违规承诺（保证、100%、绝对等）≥1次 → 综合分 × 0.3
4. 正常无违规 → 综合分不变
```

**设计理念**：
- 辱骂客户是职业道德底线，一票否决，直接0分
- 违规承诺是业务风险，大幅扣分但保留一定分数
- 合规性是前置校验，优先于其他评分

## 六、综合分计算

### 计算公式

```
综合分（计算前）= 专业知识分×40% + 服务态度分×25% + 沟通效率分×15% + 问题解决分×20%

综合分（最终）= 合规性校验(综合分)
```

### 权重说明

| 维度 | 权重 | 说明 |
|------|------|------|
| 专业知识 | 40% | 客服核心能力，权重最高 |
| 服务态度 | 25% | 情绪管理能力，重要但次于专业知识 |
| 沟通效率 | 15% | 效率重要但不是第一优先级 |
| 问题解决 | 20% | 结果导向，但需区分客服能力和客户执行 |

## 附录：原评分体系对照

### 原评分公式

```
综合分 = 业务分×60% + 情绪管理分×25% + 效率分×15%

业务分 = 目标完成率×100
情绪管理分 = 60 + 烦躁值下降奖励 - 超阈值惩罚
效率分 = 60 + 完成度奖励 + 轮数奖励
```

### 原评分问题总结

1. **效率分轮数奖励独立于业务产出** → 对话越早崩溃效率分越高
2. **业务分只算目标完成率** → 专业解答但目标未完成只得低分
3. **情绪管理基础分过高** → 完全不回应也有60分
4. **缺少合规校验** → 辱骂客户综合分还能有12分

### 11.6 权限校验设计

#### 后端权限装饰器

```python
# backend/app/core/auth.py

from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import JWTError, jwt
from sqlalchemy.orm import Session
from app.core.database import get_db
from app.models import User

security = HTTPBearer()

SECRET_KEY = "your-secret-key"  # 应从环境变量读取
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 60 * 24  # 24小时

def create_access_token(data: dict):
    """生成 JWT Token"""
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security),
    db: Session = Depends(get_db)
) -> User:
    """获取当前登录用户"""
    try:
        payload = jwt.decode(credentials.credentials, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload.get("sub")
        if username is None:
            raise HTTPException(status_code=401, detail="无效的认证凭证")
    except JWTError:
        raise HTTPException(status_code=401, detail="无效的认证凭证")

    user = db.query(User).filter(User.username == username).first()
    if user is None:
        raise HTTPException(status_code=401, detail="用户不存在")
    return user

def require_admin(current_user: User = Depends(get_current_user)) -> User:
    """要求管理员权限"""
    if current_user.role != "admin":
        raise HTTPException(status_code=403, detail="权限不足")
    return current_user

def require_trainee(current_user: User = Depends(get_current_user)) -> User:
    """要求学员权限"""
    if current_user.role != "trainee":
        raise HTTPException(status_code=403, detail="权限不足")
    return current_user
```

```jsx
import { Navigate } from 'react-router-dom';

export function PrivateRoute({ children, requiredRole }) {
  const token = localStorage.getItem('token');
  const user = JSON.parse(localStorage.getItem('user') || '{}');

  // 未登录，跳转登录页
  if (!token) {
    return <Navigate to="/login" replace />;
  }

  // 权限不足，跳转首页
  if (requiredRole && user.role !== requiredRole) {
    return <Navigate to="/" replace />;
  }

  return children;
}
```

### 14.3 登录状态管理（AuthContext）

```jsx
// frontend/src/contexts/AuthContext.jsx

import { createContext, useContext, useState, useEffect } from 'react';
import { useNavigate } from 'react-router-dom';
import { message } from 'antd';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(localStorage.getItem('token'));
  const [loading, setLoading] = useState(true);
  const navigate = useNavigate();

  // 初始化：检查 Token 是否有效
  useEffect(() => {
    const checkAuth = async () => {
      const savedToken = localStorage.getItem('token');
      const savedUser = localStorage.getItem('user');

      if (savedToken && savedUser) {
        try {
          // 可选：调用 /api/auth/me 验证 Token 有效性
          // const res = await fetch('/api/auth/me', { headers: { Authorization: `Bearer ${savedToken}` } });
          // if (res.ok) { ... } else { logout(); }
          setUser(JSON.parse(savedUser));
          setToken(savedToken);
        } catch (err) {
          logout();
        }
      }
      setLoading(false);
    };
    checkAuth();
  }, []);

  // 登录
  const login = (token, userData) => {
    localStorage.setItem('token', token);
    localStorage.setItem('user', JSON.stringify(userData));
    setToken(token);
    setUser(userData);
    message.success('登录成功');
  };

  // 登出
  const logout = () => {
    localStorage.removeItem('token');
    localStorage.removeItem('user');
    setToken(null);
    setUser(null);
    message.info('已退出登录');
    navigate('/login');
  };

  // 是否是管理员
  const isAdmin = user?.role === 'admin';

  // 是否是学员
  const isTrainee = user?.role === 'trainee';

  return (
    <AuthContext.Provider value={{ user, token, login, logout, isAdmin, isTrainee, loading }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth must be used within AuthProvider');
  }
  return context;
}
```

```jsx
// frontend/src/components/PrivateRoute.jsx

import { Navigate, useLocation } from 'react-router-dom';
import { Spin } from 'antd';
import { useAuth } from '../contexts/AuthContext';

export function PrivateRoute({ children, requiredRole }) {
  const { user, token, loading } = useAuth();
  const location = useLocation();

  // 加载中
  if (loading) {
    return (
      <div style={{ display: 'flex', justifyContent: 'center', alignItems: 'center', height: '100vh' }}>
        <Spin size="large" />
      </div>
    );
  }

  // 未登录，跳转登录页（记录原目标路径）
  if (!token || !user) {
    return <Navigate to="/login" state={{ from: location.pathname }} replace />;
  }

  // 权限不足，跳转首页
  if (requiredRole && user.role !== requiredRole) {
    return <Navigate to="/" replace />;
  }

  return children;
}
```

### 14.7 API 封装（带 Token 拦截器）

```jsx
// frontend/src/api/auth.js

import axios from 'axios';
import { useNavigate } from 'react-router-dom';

// 创建 axios 实例
const api = axios.create({
  baseURL: '/api',
  timeout: 30000,
});

// 请求拦截器：自动携带 Token
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器：401 自动跳转登录页
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token');
      localStorage.removeItem('user');
      // 跳转登录页（需要在外部处理，这里只清除状态）
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

// 登录 API
export async function loginApi(username, password) {
  const res = await axios.post('/api/auth/login', { username, password });
  return res.data;
}

// 获取当前用户信息
export async function getCurrentUser() {
  const res = await api.get('/auth/me');
  return res.data;
}

export default api;
```

```jsx
              <Route path="dynamic-exam" element={<DynamicExam />} />

              {/* 管理后台（需管理员权限） */}
              <Route path="admin" element={
                <PrivateRoute requiredRole="admin">
                  <AdminDashboard />
                </PrivateRoute>
              } />
            </Route>

            {/* 404 */}
            <Route path="*" element={<Navigate to="/" replace />} />
          </Routes>
        </AuthProvider>
      </BrowserRouter>
    </ConfigProvider>
  );
}

export default App;
```
